# Состав пакета

Для установки нужна собственная копия Cyber Manhunt. Пакет содержит
перевод, установщики и двоичные разницы, а не полную игру.

Windows-пакет включает Python и сторонние библиотеки. Их лицензии
сохранены в `Windows/runtime`, включая `LICENSE.txt` и файлы LICENSE
в каталогах библиотек. Права на игру и её материалы принадлежат их
правообладателям. Этот файл не меняет условия сторонних лицензий.
