# Cyber Manhunt — русский перевод

Русификатор Cyber Manhunt для macOS и экспериментальный пакет Windows.
Текущая редакция: **12**.

## Скачать и установить

Откройте [последний релиз](https://github.com/PhoenixDeveloper/cyber-manhunt-rus/releases/latest)
и скачайте ZIP для своей платформы. Файлы `Source code` — снимки
репозитория; для установки используйте архив с названием платформы.

- **macOS:** закройте игру, распакуйте архив и запустите
  `macOS/Установить.command`. Подробности: [инструкция macOS](macOS/Инструкция.txt).
- **Windows:** закройте игру, распакуйте архив и запустите
  `Windows/Install.cmd`. Подробности: [инструкция Windows](Windows/Инструкция.txt).
- В игре оставьте язык **English**. Перевод занимает английский слот.
- Для отката используйте штатное восстановление из пакета. Сохраните
  созданную установщиком папку `CyberManhunt-RU-backup`.

Рядом с каждым релизом есть `SHA256SUMS.txt`. Внутри ZIP находится
отдельный список контрольных сумм его файлов. Архивы macOS сохраняют
признак исполняемости `.command`.

## Совместимость и проверка

macOS-пакет проверен на Steam-сборке **9369524**, версия игры **1.3.93**.
Установщик проверяет ресурсы до изменения и отказывается от неизвестных
версий. Пакет не обещает совместимость с любым обновлением игры.

Windows проверялся на ресурсах формата Windows и при обновлении/откате
в изолированных копиях. Проверки на настоящей Windows-версии игры пока нет.

Перевод использует DeepL и ручную литературную редакцию. Исправлены
выделения ряда улик, формат дат и отдельные экраны интерфейса. Игровые
имена, логины, пароли и команды, необходимые для прохождения, сохраняются
в исходном написании. Озвучка и часть надписей внутри изображений остаются
в оригинале.

Пользовательское прохождение подтвердило все задачи первой главы,
85/85 улик второй и 95/95 улик третьей. Эти результаты не означают, что
каждый экран остальных глав уже проверен. Детали проверок: [Проверка.json](Проверка.json).

Затуманивание облачков в выводах о Coral — часть исходной головоломки:
перетаскивание соответствующего источника раскрывает текст.

## История и новые редакции

[История изменений](CHANGELOG.md) ·
[Все релизы](https://github.com/PhoenixDeveloper/cyber-manhunt-rus/releases)

Редакции 3–12 опубликованы как отдельные релизы с ZIP для обеих платформ.
Для 1–2 сохранено описание истории: готовых установочных архивов нет.
В исторических пакетах исправлены только публичные материалы: удалены
личные ссылки DeepL и метаданные Finder, пересчитаны контрольные суммы.
Игровые переводы и установочная логика этих редакций сохранены.

Для новой редакции:

1. Обновите пакеты и одинаковый номер `revision` в обоих манифестах.
2. Добавьте `release-notes/vN.md` и запись в `CHANGELOG.md`.
3. Выполните `python3 tools/package_release.py --tag vN --output dist`.
4. После необходимых проверок создайте коммит и аннотированный тег `vN`,
   затем отправьте ветку и тег в GitHub.

Workflow проверит содержимое, соберёт отдельные ZIP и опубликует Release
с описанием и контрольными суммами. Он использует встроенный токен GitHub
Actions; личный API-ключ в репозитории не требуется. Ручной запуск workflow
по умолчанию только проверяет выбранную редакцию, без публикации.

## Личные данные и сторонние компоненты

Ссылки на личные глоссарии удалены; CSV можно импортировать в собственный
аккаунт DeepL. Игровые телефоны, почта и пароли в переводе относятся к
персонажам и механике. См. также [состав пакета](NOTICE.md).
