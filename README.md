# Cyber Manhunt — русский перевод, редакция 3

Архивная редакция: Обучение и интерфейс.

Обучение и интерфейс: кнопки досье, поля паролей, заголовки и точность формулировок.

Для установки используйте архив с названием вашей платформы из [Releases](https://github.com/PhoenixDeveloper/cyber-manhunt-rus/releases). В игре оставьте English. Инструкции находятся в папках macOS и Windows. Windows экспериментален; нужна собственная копия игры.

Поддерживаемая macOS-сборка: Steam 9369524, игра 1.3.93. Сохраните созданную установщиком резервную копию. Для текущего прохождения рекомендуется последняя редакция. Личные ссылки DeepL и метаданные Finder исключены из этой публичной копии.
