# Редакция 15 — подсказка цифрового замка

В окне цифрового пароля телефона исправлена обрезанная подсказка «Дебют + День рождения + День памяти».

Поле увеличено по высоте, настроен подбор размера шрифта с переносом строк. Текст остаётся внутри окна. Сообщение о неверном пароле размещено ниже подсказки, выше кнопки OK.

Изменена только вёрстка: три объекта интерфейса. Тексты, ввод цифр, пароли, улики и условия открытия файлов сохранены. Все предыдущие исправления включены.

## Установка

Скачайте ZIP своей платформы, закройте игру и запустите установщик. Поддерживается обновление с редакции 14. В игре оставьте English.

macOS: Steam 9369524, игра 1.3.93. Windows остаётся экспериментальным пакетом без проверки на настоящей Windows-сборке. Контрольные суммы — SHA256SUMS.txt.
